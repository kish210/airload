# Mini DCS Aviation Form Library v2

Generated starter package, completed with full field definitions.

Includes:
- 47 controlled form-definition templates (ACTIVE), each with:
  - form-specific fields
  - workflow lifecycle
  - role-based permissions
  - validation rules
  - UI layout metadata
  - PDF rendering metadata
  - source/provenance references
- form catalog
- lifecycle/workflow rules
- data dictionary
- JSON Schemas (form definition validator + flight/passenger/loadsheet data)
- Claude implementation prompts
- form registry

These are implementation templates, not official reproductions of ICAO/IATA/FAA/EASA forms.
Verify every operational/regulatory requirement against current authorized sources before production use.
Never label a form as official ICAO/IATA/FAA/EASA unless the exact official source and applicable rights are verified.
