# Aviation Form Library v2

The form library is data-driven. A form is a versioned definition, not merely a PDF.

Each form definition contains:
- identity
- category
- owner department
- lifecycle
- fields
- validation
- permissions
- workflow
- output templates
- source/provenance metadata

Never label a form as ICAO/IATA/FAA/EASA official unless the exact official source and applicable rights are verified.
